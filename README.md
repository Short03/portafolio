# Portafolio · Adrián Short

Sitio personal estático (HTML y CSS) con CV descargable. Se publica en Vercel.

## Archivos

- `index.html`: la página completa.
- `cv-adrian-short.pdf`: CV que se descarga desde el botón "Descargar CV".

## Actualizar el CV

1. Edita tu CV y expórtalo a PDF.
2. Reemplaza `cv-adrian-short.pdf` con el mismo nombre.
3. `git add . && git commit -m "docs: actualiza CV" && git push`. Vercel publica el cambio solo.
